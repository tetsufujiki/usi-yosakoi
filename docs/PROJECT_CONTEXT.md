# usi-yosakoi Project Context

## この文書の役割

この文書は、`usi-yosakoi` の事業上・編集上の前提をまとめたものです。実装仕様は [IMPLEMENTATION_PROFILE.md](./IMPLEMENTATION_PROFILE.md)、Codexの作業手順は [CODEX_WORKFLOW.md](./CODEX_WORKFLOW.md) を参照してください。

## サイトの位置づけ

- `yosakoi.united-studio.com` 用の独立サイト
- UNITED STUDIOによる、よさこい演舞楽曲制作の専門サイト
- UNITED STUDIOから独立した別ブランドではなく、よさこい領域に特化したサイト
- 制作実績を探せる作品アーカイブと、本気で楽曲制作を検討しているチームへの情報提供を目的とする

## 問い合わせに対する考え方

このサイトは、問い合わせ数を最大化する一般的なランディングページではありません。制作方針や実績を理解したうえで相談したいチームに、判断材料と適切な連絡手段を提供します。

- 基本料金表は掲載しない
- 「無料見積もり」を主要訴求にしない
- 「お気軽に誰でもどうぞ」というトーンにしない
- Contactは、具体的に制作を検討しているチーム向けとする
- 年間の制作スケジュールは、既存チームを中心におおむね決まっている
- 新規依頼は、制作時期・内容を確認し、空き枠を調整できる場合に限り承る

相談への入口は閉じませんが、制作枠を無条件に約束する表現や、価格だけで比較を促す表現は避けます。

## 作品アーカイブ

よさこい作品はYouTube実績が多く、年度・チーム・作品名で整理しやすいため、UNITED STUDIO全体の実績へ無理に統合せず、独立したアーカイブとして運用します。

- チームごとの長い紹介より、制作実績の探索性を優先する
- 作品数が増えても探しやすく、更新しやすい構造を維持する
- 写真の個別登録を前提にせず、自動生成サムネイルを標準とする
- YouTubeを大量に初期読み込みしない

データ追加の詳細は [ARCHIVE_DATA_GUIDE.md](./ARCHIVE_DATA_GUIDE.md)、年次追加用の入力書式は [NEW_YOSAKOI_WORK_TEMPLATE.md](./NEW_YOSAKOI_WORK_TEMPLATE.md) を参照してください。

## 公開・移行方針

- 旧WordPressページ `/yosakoi-matsuri` は現時点では変更しない
- 旧URLから新サイトへのリダイレクトは、新サイトの公開準備が整ってから別途行う
- 現時点では `noindex` 方針を維持する
- metadata、OGP、canonical、robots、旧URLリダイレクトは公開判断を伴うため、個別の明示指示なしに変更しない

## 判断に迷った場合

新規問い合わせを広く集める施策よりも、作品の探しやすさ、制作方針の正確さ、既存の世界観、制作可能枠に対する誠実な案内を優先します。
